- **S4** Parent design notes, M5 (not user words): `agents/odd-verify.md` gains a short skeptical default ("an item is unmet until your own observed evidence shows it met") and a compact calibration block of worked verdict examples: (a) writer reports tests pass but the spec example was never run -> unverified, counts as unmet; (b) suite green but the spec's exact error text differs -> blocker; (c) behavior already present at the baseline and not asked to change -> pre-existing advisory, not a blocker; (d) a test loosened or skipped to reach green without spec authorization -> blocker; (e) evidence matches the spec example exactly -> met. Examples restate existing rules of the agent body; they add no new rule and drop no qualifier. Body growth about 1.5 KB at most. Basis: Anthropic "Harness design for long-running apps" (2026-03-24): a standalone evaluator tuned to be skeptical and calibrated with few-shot examples. Basis: OpenAI "Run long-horizon tasks with Codex" (milestones with acceptance criteria, stop-and-fix) and Anthropic "Effective harnesses for long-running agents" (feature list with checks, end each session mergeable).
