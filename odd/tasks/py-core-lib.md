- **S2** Exit criterion, verbatim: "Fixtures from Phase 1 load and round-trip byte-compatibly where the format is stable." Owners: Session state, Plugin-wide state, Scratch, Logs (`state.ts` writes `hooks.log`) and Data dir env belong to T1 (`state`, `scratch`); the stats and retro output schemas to T3; the tasks-lint output schema to T4. `persisted-formats.md` marks no format as byte-unstable; the only stated exception is the Logs message text ("a port matches the line shape (timestamp, event name, colon, message), not the message"). Check: each owner adds its own `tests/lib/test_fixtures_<module>.py` that loads its JSON fixtures through the Python model or serializer and writes them back byte-identical (placeholders such as `<TIMESTAMP>` and `<SANDBOX>` are kept as values); T1 also asserts Data dir env resolution matches every row of its fixture table, the Scratch listing (modes 0700) matches a fresh Python run, and a Python log line matches the Logs line shape.
- **S3** Exit criterion, verbatim: "Lock semantics (exclusive create, stale takeover, owned release, EPERM/ESRCH handling) pass cross-process tests, including kill -9 injection." v9 reference: `plugins/odd-claude/src/lib/lock.ts`, `pid.ts` and their specs. Check: `tests/lib/test_lock.py` runs real child processes (no mocks of the lock) covering each of the four named behaviors, including a holder killed with SIGKILL whose lock is then taken over, and a lock file naming a live pid owned by another user, such as pid 1 (EPERM from the liveness probe), that is not taken over, plus a lock file naming a dead pid (ESRCH) that is; `uv run pytest tests/lib/test_lock.py` passes 5 consecutive runs.
- **S4** Exit criterion, verbatim: "Version mismatch is rejected the same way as v9." v9 reference: `STATE_SCHEMA_VERSION=1` envelope `{version:1, sessionId, data}` (`state.ts:10`) and the output schema ids. v9 outcome, from `docs/contracts/persisted-formats.md`: Session state "a `version: 2` copy reads as `{}`"; Plugin-wide state has the "same read rules as Session state". Output schemas are stdout only and are never read back, so they have no mismatch path. Check: `tests/lib/test_state.py` feeds a `version: 2` copy of `session-state/session.json` and of `plugin-state/delegation.json` to the Python readers and asserts each reads as an empty object, with no exception.
- **S5** Doctor scope item, verbatim: "doctor (checks python/uv instead of node)". Check: `tests/lib/test_doctor.py` asserts the python and uv items with the same required/optional semantics v9 gives node, and that no node item remains.
- **S6** Consequence of L3: the mapping's phase column is corrected for lib specs outside S1. Check: in `docs/contracts/test-mapping.md`, every `src/lib/*.spec.ts` row whose module is not one of the 18 S1 modules shows phase 3, 5 or 6 (the phase whose entry consumes it, by its importers), with the reason; `src/conformance/test-mapping.spec.ts` passes; the roadmap Phase 2 scope gains one line naming the four dependency modules and pointing the rest to their consumer phase.
